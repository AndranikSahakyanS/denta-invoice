# Denta — счёт пациента

Собранная страница счёта для QR-кода из программы Denta. Счёт целиком передаётся в ссылке после «#» и рисуется на телефоне пациента; на сервер ничего не отправляется и нигде не хранится.

Исходный код — apps/invoice в репозитории Denta. Этот репозиторий обновляется только сборкой.
