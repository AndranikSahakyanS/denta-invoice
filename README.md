# Greeny — счёт клиента

Собранная страница счёта для QR-кода из программы Greeny. Счёт целиком передаётся в ссылке после «#» и рисуется на телефоне клиента; на сервер ничего не отправляется и нигде не хранится.

Исходный код — apps/invoice в репозитории Greeny. Этот репозиторий обновляется только сборкой.
